NOMAD: RoadTrip
GPS Permission Guide
FEATURES
🛰️ Real-Time Tracking: NOMAD requires hardware GPS access to calculate live speed, bearing heading, elevation, and concurrent highway routing. High accuracy / precise mode ensures zero telemetry lag.
🍎 iOS (iPhone & iPad / Safari)
1. System-Level Location Services
  • Open your iPhone Settings app.
  • Scroll down and tap Privacy & Security → Location Services.
  • Ensure the top Location Services toggle is turned ON (green).
  • Scroll down to Safari Websites (or Chrome if using Chrome on iOS).
  • Set to While Using the App and toggle Precise Location to ON.
2. Safari In-Browser Site Setting
  • While on NOMAD in Safari, tap the aA icon in the address bar.
  • Tap Website Settings → Location → select Allow.
🤖 Android (Google Chrome)
1. System GPS Permission
  • Open the phone Settings app.
  • Tap Location and make sure Use location is toggled ON.
  • Tap App permissions → select Chrome.
  • Choose Allow only while using the app and enable Use precise location.
2. Chrome Site Permission
  • While on NOMAD in Chrome, tap the Tune / Padlock icon to the left of the URL.
  • Tap Permissions → Location → select Allow.
  • Refresh the tab to establish real-time GPS lock.
